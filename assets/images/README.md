# Images Directory

This directory contains images used by the Food Delivery application.

## Required Images

The following images are referenced in the application and should be added:

### Restaurant Images
- `default-restaurant.jpg` - Default restaurant image (400x300px recommended)
- `food-hero.png` - Hero section food image (800x600px recommended)

### Food Images  
- `default-food.jpg` - Default food item image (300x200px recommended)

## Image Guidelines

- **Format**: Use JPG for photos, PNG for graphics with transparency
- **Size**: Optimize images for web (compress without losing quality)
- **Dimensions**: Use consistent aspect ratios for similar content types
- **Naming**: Use descriptive, lowercase names with hyphens

## Sample Images

You can add your own restaurant and food images here. Make sure to:
1. Use appropriate file extensions
2. Keep file sizes reasonable (< 500KB for most images)
3. Maintain consistent dimensions for similar content
4. Use descriptive filenames

## Default Images

If specific images are not found, the application will use the default images listed above.
